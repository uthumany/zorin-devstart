# Brand icon sources and credits

The language marks in DevStart identify the development profile they accompany. They do not indicate sponsorship, certification, or endorsement of DevStart.

## Android robot

Asset: `public/assets/language-icons/android.svg`, the [official Android robot head SVG](https://developer.android.com/static/images/brand/android-head_3D.svg). The SVG is included unmodified. The required attribution, also shown in the app’s Settings, is:

> The Android robot is reproduced or modified from work created and shared by Google and used according to terms described in the [Creative Commons 3.0 Attribution License](https://creativecommons.org/licenses/by/3.0/).

Source: [Android brand guidelines](https://developer.android.com/distribute/marketing-tools/brand-guidelines).

## C++

Asset: `public/assets/language-icons/cpp.svg`, the [ISO C++ logo](https://commons.wikimedia.org/wiki/File:ISO_C%2B%2B_Logo.svg), by Jeremy Kratz. Wikimedia Commons describes this simple geometric/text logo as public domain for copyright purposes and separately flags possible trademark restrictions. The Standard C++ Foundation’s [terms of use](https://isocpp.org/home/terms-of-use) expressly permit use of the unaltered C++ logo in a product related to standardized C++, provided the use does not imply endorsement. The SVG is included unmodified.

## Node.js

Asset: `public/assets/language-icons/nodejs.svg`, the [Node.js hex logo](https://nodejs.org/static/logos/nodejsHex.svg) published on the [Node.js branding page](https://nodejs.org/en/about/branding). The SVG is included unmodified and used only to identify the Node.js tooling in the Web development profile. **Node.js® is a trademark of the OpenJS Foundation.** DevStart is independent and is not endorsed by Node.js or the OpenJS Foundation. See the [OpenJS Foundation trademark policy](https://trademark-policy.openjsf.org/).

## Python

Asset: `public/assets/language-icons/python.svg`, the official two-snakes logo device published on the [Python Software Foundation logo page](https://www.python.org/community/logos/). The SVG is included unmodified and used to identify the Python profile. The app displays a separate ™ beside the image without changing the artwork and uses ® after the first prominent Python word-mark display, following the [PSF trademark guidance](https://www.python.org/psf/trademarks/). That policy permits unaltered logos for accurate nominative use to identify Python tools without prior approval.

## Rust

Assets: `public/assets/language-icons/rust-black.svg` and `rust-white.png`, the black and white Rust language cog marks from the Rust Foundation’s [official logo pack](https://rustfoundation.org/wp-content/uploads/2024/07/Rust-Foundation-Logo-Pack.zip). The artwork is included unmodified; the white PNG is used in the dark theme. The Rust and Cargo logo art is distributed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The [Rust Foundation trademark policy](https://rustfoundation.org/policy/rust-trademark-policy/) also applies. DevStart is not an official Rust Project or Rust Foundation product.

## Java

`public/assets/language-icons/java-monogram.svg` is an original, generic letter-J monogram created for DevStart. It is not the Java coffee-cup logo or Oracle’s Java affinity logo, and it does not use Oracle artwork or imply Oracle endorsement. Oracle’s [Java affinity terms](https://dev.java/community/affinity/) limit that mark to unmodified, linked website use and prohibit its use on a product; therefore that mark is not embedded here.
